# CS32 — Data Structures and Algorithms

UCLA lower-division course covering fundamental data structures, object-oriented design in C++, and algorithm analysis.

| Folder | Description |
|--------|-------------|

| [Project 4](Projects/Project4/) | **Anagram Dictionary** — hash-map backed dictionary with callback-based anagram lookup |

## Compiling

All projects use standard C++17. To compile any project:

```bash
cd Projects/Project1
g++ -std=c++17 -o game *.cpp
./game
```
